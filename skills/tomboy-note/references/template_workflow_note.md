# 工作流程與對話總結標準範本

將對話總結或技術流程文件化時，請依照下列 Markdown 結構撰寫，轉換工具會自動將其精準轉換為 Tomboy 原生排版：

```markdown
## 背景與目的
簡要說明本次任務的背景、遭遇的問題，以及解決的目標。

## 執行環境與前置需求
• 作業系統 / 硬體：Linux Mint 22 (x86_64)
• 相關套件：.NET 8 SDK, GTK3 (libgtk-3-0)
• 相關筆記：[[其他相關筆記標題]]

## 解決方案與步驟指引
• 第一步：環境檢測與問題重現
  ◦ 執行日誌檢查或除錯命令：`coredumpctl gdb ...`
  ◦ 定位關鍵呼叫堆疊
• 第二步：核心修復作業
  ◦ 編輯關鍵程式碼：`vim src/Main.cs`
  ◦ 移除容易引發崩潰之參數
• 第三步：編譯與驗證
  ◦ 執行自動化建置腳本：`./build_deb.sh`
  ◦ 執行功能測試驗證

## 關鍵技術決策與避坑指南
• 關鍵決策：**不使用 Invisible 標籤**，改用極小字級 `Size = 1` 縮放隱藏，避免觸發 GTK 排版越界 Bug。
• 注意事項：文字複製貼上時須確保保留縮排層級標籤。

## 相關資源與參考連結
• 官方文件：https://wiki.gnome.org/Apps/Tomboy
• 原始碼庫：https://github.com/sophAi/tomboy-gtk3
```
